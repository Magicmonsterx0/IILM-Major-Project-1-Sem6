# Major_Project_1_Sem6
Academic major project for semester 6 titled as 'VR Based Anatomy Training System'.

---

## ⚠️ Important Setup Instructions (Git LFS)

This Unity VR project utilizes **Git Large File Storage (LFS)** to handle high-fidelity 3D anatomical models and XR controller prefabs. 

**DO NOT use the "Download ZIP" button on GitHub.** 
Downloading the ZIP will only fetch 1-KB text pointers instead of the actual 3D meshes, resulting in broken prefabs, missing textures, and console errors when opening the project in Unity.

### Prerequisites
Before cloning the repository, you must have Git LFS installed on your system.
1. Download and install [Git LFS](https://git-lfs.com/).
2. Open your terminal or command prompt and initialize LFS by running:
   ```bash
   git lfs install
